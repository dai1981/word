📖 主な意味
  • 1 【名】（英・旧）准看護師（じゅんかんごし） かつて英国にあった、基礎的な看護資格。略 SEN。正しくは State Enrolled Nurse。可算。
  • 2 【名】国に登録された看護師（旧制度） state（国の）＋ enrolled（登録された）＋ nurse。正看護師 SRN と対。今は使われない。

⚠️ 正しくは State Enrolled Nurse と3語・大文字で書く（見出し語は小文字だが要注意）。『（英・旧)准看護師〔じゅんかんごし〕（かつてイギリスにあった看護資格の一つ。SEN と略す）』。より専門的な State Registered Nurse（正看護師、SRN）に対し、より短い訓練で基礎的・実務的な看護を行う看護師の資格だった。state（国の）＋ enrolled（登録された）＋ nurse（看護師）＝『国の名簿に登録された看護師』。SEN / SRN の区分は制度改革で現在は使われない歴史的な呼び名。可算。
⚠️ state（国の・公的な）＋ enrolled（登録された、enroll＝登録する から）＋ nurse（看護師）。正看護師は State Registered Nurse（SRN）。
🏛 語源・歴史

state（国の・公的な）＋ enrolled（登録された、enroll＝登録する から）＋ nurse（看護師）＝『国の名簿に登録された看護師』。かつての英国の准看護師資格（SEN）。正看護師は State Registered Nurse（SRN）。今は使われない。
