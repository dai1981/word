ui

名詞(略語)
発音：/ˌjuː ˈaɪ/（ユーアイ）
中学生〜 英検2級 CEFR B1 略語
UI/ユーザーインターフェース(利用者と機器の接点)
📖 主な意味
  • 1 【名詞】UI・ユーザーインターフェース User Interface の略。利用者がソフトや機器を操作する際に触れる画面・ボタン・メニューなどの接点。文中では大文字 UI
💡 使い方・例文
① a clean UI（すっきりしたUI）
見やすい画面設計
The app has a clean and simple UI.
そのアプリはすっきりしたシンプルなUIだ。
② UI design（UIデザイン）
操作画面の設計
She works in UI design.
彼女はUIデザインの仕事をしている。
⚠️ UI（見た目・操作の接点）と UX（User Experience＝使ったときの体験全体）は別概念。UIはUXの一部
⚠️ 頭字語なので大文字 UI。母音の音で始まるので冠詞は a UI（『ユー…』と子音のyの音で始まるため a）
🏛 語源・歴史

User Interface（ユーザーインターフェース）の頭文字。inter-（間）＋face（面）で『利用者と機械の間の面(接点)』を表す。
