server

名詞
発音：/ˈsɜːrvər/（サーバー）
高校生〜 英検2級 CEFR B1 日常
（IT）サーバー（情報を提供するコンピューター）／給仕人・（レストランの）店員／（テニスなどで）サーブする人／取り分け用具
📖 主な意味
  • 1 【名】（IT）サーバー データやサービスを提供するコンピューター。a web server。可算。
  • 2 【名】給仕人、（レストランの）店員 特に米で性別を問わない言い方。ask the server。
  • 3 【名】（球技で）サーブする人／取り分け用具 serve（給仕する・サーブする）＋ -er。
💡 使い方・例文
① サーバー
IT。
a web server
ウェブサーバー
② 店員
飲食店。
ask the server for the menu
店員にメニューを頼む
⚠️ 動詞 serve（仕える・給仕する・サーブする）＋ -er。『（IT)サーバー（ネットワークでほかのコンピューターにデータやサービスを提供するコンピューター・プログラム）』a web server、『給仕人・（レストランの)店員』（特に米で性別を問わない言い方）ask the server、『（テニス・バレーで)サーブする人』、『料理の取り分け用具』。可算。
⚠️ serve（仕える・給仕する・サーブする）＋ -er（〜する人・もの）。service / servant の仲間。
🏛 語源・歴史

serve（仕える・給仕する・（球技で)サーブする、ラテン語 servire＝仕える から）＋ -er（〜する人・もの）＝『給仕する人・サーブする人・提供するもの→サーバー・店員など』に由来。
