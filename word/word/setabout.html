setabout

句動詞（set about）
発音：/ˌset əˈbaʊt/（セット・アバウト）
中学生〜 英検2級 CEFR B1 句動詞
（仕事・作業に）取りかかる・着手する（set about doing）
📖 主な意味
  • 1 【句動】（仕事に）取りかかる、着手する set about doing（〜し始める）。動名詞が続く。
  • 2 【句動】（課題に）本格的に取り組み始める set about a task（仕事に着手する）。
💡 使い方・例文
① 〜し始める
set about doing。
She set about cleaning the house.
彼女は家の掃除に取りかかった。
② 仕事に着手する
本格的に始める。
He set about the task at once.
彼はすぐにその仕事に取りかかった。
⚠️ リンクの都合で setabout とつなげて書かれますが、正しくは set about（2語）です。
⚠️ 『〜し始める』は set about doing（動名詞）。set about to do とはふつう言わない。前置詞は about。
🏛 語源・歴史

set（据える・始める）＋ about（取りかかって)による句動詞。「取りかかる→着手する」。
