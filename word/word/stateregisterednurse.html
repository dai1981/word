（英・旧）正看護師（せいかんごし）（かつてイギリスにあった、専門的な訓練を受けた正規の看護師。略 SRN）（正しくは State Registered Nurse）
📖 主な意味
  • 1 【名】（英・旧）正看護師（せいかんごし） かつて英国にあった、専門的訓練を受けた正規の看護師資格。略 SRN。正しくは State Registered Nurse。可算。
  • 2 【名】国に正式登録された看護師（旧制度） state（国の）＋ registered（登録された）＋ nurse。准看護師 SEN と対。今は使われない。

⚠️ 正しくは State Registered Nurse と3語・大文字で書く（見出し語は小文字だが要注意）。『（英・旧)正看護師〔せいかんごし〕（かつてイギリスにあった看護資格の一つ。SRN と略す）』。基礎的な看護を行う State Enrolled Nurse（准看護師、SEN）に対し、より長く専門的な訓練を受け、国の名簿に正式に登録された、正規の看護師の資格だった。state（国の）＋ registered（登録された）＋ nurse＝『国に正式に登録された看護師』。SRN / SEN の区分は制度改革で現在は使われない歴史的な呼び名。可算。
⚠️ state（国の・公的な）＋ registered（登録された、register＝登録する から）＋ nurse（看護師）。准看護師は State Enrolled Nurse（SEN）。
🏛 語源・歴史

state（国の・公的な）＋ registered（登録された、register＝登録する から）＋ nurse（看護師）＝『国に正式に登録された看護師』。かつての英国の正看護師資格（SRN）。准看護師は State Enrolled Nurse（SEN）。今は使われない。
